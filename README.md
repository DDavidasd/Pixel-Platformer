# Pixel-Platformer
Unity 2D pixel-art platformer game (Thesis Project). Independently developed in C# from concept to testing, using custom Aseprite assets. Applied SOLID (SRP, OCP, LSP), DRY, and KISS principles. Implemented PlayerPrefs saving, parallax backgrounds, and a Singleton AudioManager.

Release link: https://github.com/DDavidasd/Pixel-Platformer/releases/tag/v1.0
